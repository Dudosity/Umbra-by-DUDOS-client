# Umbra by DUDOS — клиенты

Официальные сборки **Windows** и **Android** для Umbra by DUDOS.

## Скачать

1. **Сайт (предпочтительно):** [dudos.sbs → Клиенты](https://dudos.sbs/#downloads)
2. **GitHub Releases:** [последний релиз](https://github.com/Dudosity/Umbra-by-DUDOS-client/releases/latest)

Не скачивайте клиент из сторонних каналов.

## Проверка

- Сверьте **SHA256** с `SHA256SUMS` в релизе и с блоком на сайте.
- Отчёты **VirusTotal** — по ссылкам в релизе и на сайте.

## Предупреждения ОС

Windows SmartScreen и установка Android «из неизвестного источника» нормальны без Authenticode / Google Play. Якорь доверия: `dudos.sbs`, GitHub-релиз и совпадение SHA256.
